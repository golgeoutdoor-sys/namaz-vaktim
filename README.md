# Namaz Vaktim 1.4.0

Tam uygulama yapısı: ilk açılış konum/şehir seçimi, namaz vakitleri ve geri sayım, sabit kerahat vakitleri, Günün Ayeti, sağ üst menü, Nasıl Kılınır, Ayetler/Kur’an okuyucu, Sure-Ayet bul, Dualar, Ayarlar, bildirim dakikası seçimi ve Yeşil/Gece teması.

## Kur’an kaynağı
Kur’an okuyucu 604 sayfalık Al Quran Cloud Mushaf sayfalarını çevrimiçi açar; yakınlaştırma WebView tarafından desteklenir. Ayet araması Al Quran Cloud API kullanır.

## Derleme
GitHub Actions içindeki Android workflow `gradle assembleDebug` ile APK üretir.
